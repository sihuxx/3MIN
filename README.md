# 3분만 — 청소년 금연 실천 웹앱

담배 생각이 날 때 SOS 버튼을 누르면 마스코트 호롱이와 함께 3분을 버티는 웹앱.
2026학년도 서울디지텍고 흡연예방 공모전(앱·웹 제작 분야) 출품작.

## 바로 실행

- `3분만_바로실행.html` 파일을 더블클릭하면 브라우저에서 바로 열리는 구조
- 화면 크기에 따라 자동으로 바뀌는 반응형 구조
  - 휴대폰(~599px): 하단 탭이 있는 앱 화면
  - 태블릿(600~899px): 가운데 폰 모양 화면
  - 컴퓨터(900px~): 왼쪽 사이드바 메뉴 + 2단 레이아웃, SOS·온보딩은 가운데 집중 화면
- 첫 화면의 **예시 데이터로 둘러보기**를 누르면 12일째 사용자의 기록이 채워진 상태로 체험 가능 (심사·시연용)
- 글꼴(Gothic A1)은 인터넷이 연결돼 있을 때 적용, 오프라인에서는 기본 고딕으로 대체

## 개발 환경에서 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # dist 폴더로 배포용 빌드
```

`3분만_바로실행.html` 다시 만들기 (파일 하나로 묶은 버전):

```bash
# macOS / Linux / Git Bash
SINGLE=1 npx vite build
# Windows PowerShell
$env:SINGLE=1; npx vite build
```

결과물은 `dist-single/index.html`에 생성.

## 기술 스택

- React 19 + TypeScript + Vite
- 데이터 저장: 브라우저 localStorage (서버 없음, 기록이 내 기기에만 남는 구조)
- 마스코트 애니메이션: SVG SMIL 애니메이션
- 파도 소리·효과음: Web Audio API로 직접 만든 소리 (음원 파일 없음, `src/sfx.ts`)
  - 시작, 미션 완료, 3분 성공, 마지막 10초 째깍, 호흡 단계, 방울 터뜨리기, 정답·오답
  - 나 화면에서 효과음 켜고 끄기
- 진동 호흡 가이드: Vibration API (지원하는 휴대폰에서만 동작)
- 공유: Web Share API (지원하지 않으면 클립보드 복사)

```
src/
├─ App.tsx            화면 전환과 앱 상태
├─ store.ts           저장소, 날짜·통계 계산, 스티커 조건, 예시 데이터
├─ content.ts         미션, 거절 연습 상황, OX 퀴즈 문제
├─ components/
│  ├─ Mascot.tsx      마스코트 호롱이 (표정 5종: happy, calm, cheer, worried, sleepy)

│  └─ ui.tsx          아이콘, 상단바, 하단 탭, 강도 막대, 토글, 태그, 컴퓨터 화면 감지(useDesktop)
└─ screens/           화면별 컴포넌트
```

## 미션 (핵심 기능)

강도 체크에서 고른 장소·기분·함께 있는 사람에 맞춰 미션 3개를 고르는 구조 (`pickMissions`, `src/content.ts`).
미션마다 화면에서 실제로 하는 방식이 다름 (`src/components/MissionCard.tsx`).

| 미션 | 방식 |
| --- | --- |
| 4-7-8 호흡 | 원이 커지고 작아지며 들이쉬기·참기·내쉬기를 세어 줌, 2번 반복하면 완료 |
| 물 마시기 / 손 씻기 / 걷기 | 30초·20초·30초 타이머 |
| 스트레칭 | 동작 3개를 10초씩 차례로 안내 |
| 버블 팡 | 미니게임에서 연기 방울 15개 터뜨리면 자동 완료 |
| 친구 알리기 | 공유 창으로 “나 참는 중” 메시지 보내기 |
| 이유 다시 보기 | 온보딩에서 고른 금연 이유, 버틴 날, 아낀 돈을 다시 보여줌 |
| 껌·사탕 | 먹고 나서 누르기 |

- 미션을 끝낼 때마다 호롱이가 응원하고 XP 10 지급
- 완료한 미션은 기록에 저장, 결과 화면에 표시
- 기록 화면에서 미션별 평균 강도 감소를 계산해 “나한테 제일 잘 듣는 미션” 안내

## 반응형

- 휴대폰: 앱 높이를 화면 높이에 고정, 화면마다 안쪽 스크롤 → 하단 시트·버튼이 화면 밖으로 밀리지 않는 구조
- 360x640 같은 짧은 화면: 홈 글자·패널 크기 축소, 체크 화면의 "3분 버티기 시작" 버튼 하단 고정
- 가로 휴대폰: 태블릿 틀 대신 휴대폰 화면 그대로 사용
- 600~899px 태블릿: 가운데 앱 틀 / 900px 이상 컴퓨터: 왼쪽 사이드바 + 2열 화면
