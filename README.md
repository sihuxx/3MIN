# 3분만 — 청소년 금연 실천 웹앱

담배 생각이 날 때 SOS 버튼을 누르면 마스코트 호롱이와 함께 3분을 버티는 웹앱.
2026학년도 서울디지텍고 흡연예방 공모전(앱·웹 제작 분야) 출품작.

## 바로 실행

- `3분만_바로실행.html` 파일을 더블클릭하면 브라우저에서 바로 열리는 구조
- 화면 크기에 따라 자동으로 바뀌는 반응형 구조
  - 휴대폰(~599px): 하단 탭이 있는 앱 화면
  - 태블릿(600~899px): 가운데 폰 모양 화면
  - 컴퓨터(900px~): 왼쪽 사이드바 메뉴 + 2단 레이아웃, SOS·온보딩은 가운데 집중 화면
- 첫 화면의 **예시 데이터로 둘러보기**를 누르면 12일째 사용자의 기록이 채워진 상태로 체험 가능 (심사·시연용)
- 글꼴(Gothic A1)은 인터넷이 연결돼 있을 때 적용, 오프라인에서는 기본 고딕으로 대체

## 개발 환경에서 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # dist 폴더로 배포용 빌드
```

`3분만_바로실행.html` 다시 만들기 (파일 하나로 묶은 버전):

```bash
# macOS / Linux / Git Bash
SINGLE=1 npx vite build
# Windows PowerShell
$env:SINGLE=1; npx vite build
```

결과물은 `dist-single/index.html`에 생성.

## 기술 스택

- React 19 + TypeScript + Vite
- 데이터 저장: 브라우저 localStorage (서버 없음, 기록이 내 기기에만 남는 구조)
- 마스코트 애니메이션: SVG SMIL 애니메이션
- 파도 소리·효과음: Web Audio API로 직접 만든 소리 (음원 파일 없음, `src/sfx.ts`)
  - 시작, 미션 완료, 3분 성공, 마지막 10초 째깍, 호흡 단계, 방울 터뜨리기, 정답·오답
  - 나 화면에서 효과음 켜고 끄기
- 진동 호흡 가이드: Vibration API (지원하는 휴대폰에서만 동작)
- 공유: Web Share API (지원하지 않으면 클립보드 복사)

## 미션 (핵심 기능)

강도 체크에서 고른 장소·기분·함께 있는 사람에 맞춰 미션 3개를 고르는 구조 (`pickMissions`, `src/content.ts`).
미션마다 화면에서 실제로 하는 방식이 다름 (`src/components/MissionCard.tsx`).

| 미션 | 방식 |
| --- | --- |
| 숨 크게 세 번 | 원이 커지고 작아지며 들이쉬기 3초·참기 1초·내쉬기 4초를 세어 줌, 3번 반복(약 24초)하면 완료 |
| 물 마시기 / 손 씻기 / 걷기 | 30초·20초·30초 타이머 |
| 스트레칭 | 동작 3개를 10초씩 차례로 안내 |
| 버블 팡 | 미니게임에서 연기 방울 15개 터뜨리면 자동 완료 |
| 친구 알리기 | 공유 창으로 “나 참는 중” 메시지 보내기 |
| 이유 다시 보기 | 온보딩에서 고른 금연 이유, 버틴 날, 아낀 돈을 다시 보여줌 |
| 껌·사탕 | 먹고 나서 누르기 |

- 미션을 끝낼 때마다 호롱이가 응원하고 XP 10 지급
- 완료한 미션은 기록에 저장, 결과 화면에 표시
- 기록 화면에서 미션별 평균 강도 감소를 계산해 “나한테 제일 잘 듣는 미션” 안내

## 예방 모드 홈 (안 피우는 학생)

- 온보딩에서 예방 모드를 고르면 홈이 "오늘의 예방" 중심으로 바뀌는 구조
- 오늘의 거절 연습: 날짜마다 바뀌는 친구 권유 상황 1개, 맞는 거절을 고르면 완료 + 거절 연습 횟수 +1
- 오늘의 성분: "담배 속 ○○, 또 어디에 들어있을까?" 3지선다, 답하면 그림과 설명 표시
- 둘 다 하면 "오늘의 예방 2/2", 며칠 연속 했는지 표시
- 아래에 "흔들릴 때 누르기" SOS 버튼 (궁금하거나 권유받았을 때)

## 미션 고르는 방식

- 장소·기분·같이 있는 사람마다 점수를 더하고, 무작위 점수(0~5)를 섞어서 같은 상황이어도 매번 조금씩 다른 3개
- 지난번에 한 미션은 점수를 깎아서 연속으로 같은 미션이 덜 나오는 구조
- 같은 종류 미션이 3개 겹치지 않게 조절

## 조심할 시간 알림

- 기록에서 가장 많이 참은 시간대(1시간 단위)와 그때 주로 있던 장소·기분을 찾아 홈에 "조심할 시간" 카드로 표시 (기록 3개 이상부터)
- 위험 시간 15분 전부터 1시간 동안은 카드가 진한 주황으로 바뀌며 "지금 조심할 시간!" 표시
- 카드를 누르면 시간대 비율, 그 장소·기분에 맞는 미리 해둘 미션 3개, 10분 전 알림 켜기, 바로 3분 버티기 시작
- 알림은 브라우저 알림 + 진동 + 효과음, 앱(탭)이 열려 있는 동안만 동작하는 구조 (서버 푸시 없음)
- 나 → 설정에서도 켜고 끄기 가능

| 탭 | 내용 |

| 거절 연습 | 메신저 대화처럼 친구 권유 상황에서 거절 답 고르기 |
| OX 퀴즈 | 10문제, 진행 막대(맞힌 문제 주황), O·X 큰 버튼, 틀리면 흔들림 + 호롱이 해설 |
| 성분 까보기 | 맨 위 "담배가 몸에 하는 일" 사람 그림(뇌·입·폐·심장·피부·다리 점을 누르면 해당 부위가 주황으로 바뀌고 설명 표시), 담배 종류별 그림을 누르면 성분 이름이 연기처럼 하나씩 피어올라 흔들리며 사라지고 실제 성분 설명 표시, 성분 6가지는 누르면 배기가스·살충제·아스팔트·휘발유·포르말린·건전지 그림으로 보여주는 카드 |
| 숨 체크 | 버튼을 꾹 누른 채 "후~" 길게 내쉰 시간을 재서 기록, 처음·최고·달라진 시간과 최근 7번 막대 그래프 |

### 숨 체크 방식

- 숨 크게 들이쉬고, 내쉬는 동안 버튼을 꾹 누르고 있다가 떼면 측정 끝
- 0.8초보다 짧으면 저장 안 함, 최대 60초
- 지난번 기록과 비교한 문구 표시
- 병원 폐활량 검사가 아니라 내 기록끼리 비교하는 용도라는 안내 표시

### 성분 까보기 출처

- 질병관리청 청소년 담배 예방 자료, 국민건강보험공단 건강iN
